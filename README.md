# sccharts-lite server

A cut-down build of the KIELER SCCharts language server, compiled with plain Maven on JDK 21.
No Tycho, no p2 target platform, no OSGi. Everything that is not KIELER's own code comes from
Maven Central.

Status: experiment. The shaded server passes the SCCharts Lab extension's three server test
suites (`server-smoke`, `server-diagnostics`, `server-codegen`) with the extension's diagnostics
patch applied on top.

| | upstream fat JAR | this build |
|---|---|---|
| size | 93.8 MB | 33.7 MB |
| clean build | Tycho, ~14 min CI | `mvn clean install`, ~1 min |
| JDK | 17 (built), 11+ (run) | 21 |
| KLighD / ELK / Xtext / lsp4j | 3.0.2 / 0.9.1 / 2.34 / 0.20 | 3.1.0 / 0.11.0 / 2.37 / 0.23.1 |

## Layout

- `upstream/` — sparse clone of kieler/semantics (git-ignored). `scripts/import-upstream.sh`
  copies the kept plugins' `src`, `src-gen`, `resources`, `system` and `META-INF/services`
  into `modules/`, leaving the OSGi metadata behind. Imported from commit `5f02d129` (2025-10-07).
- `modules/<plugin>/pom.xml` — generated by `scripts/generate-poms.mjs` from a dependency table;
  edit the table, not the poms. Versions and exclusions live in the root `pom.xml`.
- `server/` — maven-shade module producing `server/target/sccharts-lite-server.jar`,
  main class `de.cau.cs.kieler.language.server.LanguageServer`.

## Build

```sh
mvn -B clean install -DskipTests
```

## What was removed relative to upstream's language server

- Languages: Esterel, Lustre, KiVis, verification, and the pragmatics KGraph/ELK text languages.
- `kicool.ui`: everything but `synthesis/`, `klighd/` (setup, syntheses, action ids) and
  `kitt/tracing`. The compiler view, console, wizards, preferences, JDT-based Java parser and
  AST synthesis are gone. Eclipse-only actions survive as id-only stubs so syntheses still
  attach them; the Piccolo `TracingEdgeNode` is a headless data holder.
- `sccharts.ui`: everything but `synthesis/`. Debugging (breakpoints), the Xtext editor
  integration, the wizard and the editor-cursor `SmartCollapseHook` are gone.
- `simulation.ide`: the Jetty/WebSocket visualization server (`server/` package) and the remote
  values processor. `keith/simulation/startVisualizationServer` now reports that it is unavailable.
  `SimulationPreferences` keeps values in a map instead of a JFace preference store.
- `kicool.ide`: the EMF Compare tracing tree comparator.
- The `kico`/`scc` command-line front ends and their vendored picocli.
- Transitive ballast cut at the pom level: Eclipse workbench and e4 (via `elk.core.service`),
  JNA (via `core.resources`), the Jakarta EE API set (via sprotty-server), EMF Edit, the
  StringTemplate/ANTLR 2 tool jars, log4j 2.

## What still needs doing

- The SCCharts Lab diagnostics patch (`server-src/` in the extension) compiles unchanged
  against this jar, and all 18 bytecode hooks apply once the `notify()` matcher in
  `BuildPatch` accepts an interface owner (newer compilers emit `BlockingQueue.notify`). In a
  fork those hooks should become source edits here and `BuildPatch` should go away.
- `org.eclipse.core.runtime`, `core.resources`, `equinox.*` and `org.eclipse.osgi` stay
  (about 2.5 MB) because `kicool`, `simulation` and `sccharts` use `IStatus`, `Platform`,
  `IPath` and `IFile`.
- Xtext's content-assist ANTLR parsers for the non-SCCharts grammars are still generated code
  in `src-gen`; re-running the MWE2 workflows without content assist would drop several MB.
- Licensing: the semantics sources carry EPL-1.0 headers, KLighD is EPL-2.0; keep both notices.
